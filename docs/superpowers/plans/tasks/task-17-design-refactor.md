## 4. Отключение системной клавиатуры на touch-устройствах

**Files:**

**Дефект.** Поле ввода вызывает системную клавиатуру, которая дублирует собственную раскладку и перекрывает пол-экрана. Атрибут `inputMode="none"` был предусмотрен планом, но потерялся при исправлении рендера.

- [x] **Step 1: Подавить системную клавиатуру только на touch-устройствах**

`inputMode="none"` безусловно сломает ввод на десктопе с сенсорным экраном и не даст печатать там, где физическая клавиатура есть. Определять по ширине окна неверно — планшет шире 768px.

Определять по возможности точного указания:

```tsx
const [coarsePointer, setCoarsePointer] = useState(false)

useEffect(() => {
  setCoarsePointer(window.matchMedia('(pointer: coarse)').matches)
}, [])
```

Затем: `inputMode={coarsePointer ? 'none' : 'text'}` и `autoFocus={!coarsePointer}`.

Проверка в `useEffect`, а не при рендере — иначе разметка сервера и клиента разойдутся.

- [x] **Step 2: Показывать собственную раскладку по тому же признаку**

Сейчас раскладка скрыта через `md:hidden`, то есть привязана к ширине. Заменить на условие по `coarsePointer`, чтобы раскладка и подавление системной клавиатуры включались вместе.

- [x] **Step 3: Проверить**

На телефоне: тап по полю не вызывает системную клавиатуру, ввод идёт только с собственной раскладки. На десктопе: клавиатура работает, поле получает фокус автоматически, собственная раскладка скрыта.

## 5. Исправление анимации порядка черт

**Files:**
- Modify: `src/features/reference/stroke-order.tsx`
- Modify: `src/app/globals.css`

**Дефект.** Анимация задана с фиксированным `stroke-dasharray: 120`, тогда как реальная длина черт в KanjiVG колеблется от 44 до 506 единиц. У **205 черт из 417** длина превышает 120, поэтому пунктир повторяется вдоль пути и черта начинает проявляться не с начала, а с середины.

- [x] **Step 1: Вычислить длину каждой черты при рендере**

Компонент читает SVG на сервере. Длину пути там измерить нельзя (нет DOM), но можно оценить по контрольным точкам и задать каждой черте собственный `stroke-dasharray` через инлайновый стиль.

Добавить в `stroke-order.tsx`:

```tsx
function approxLength(d: string): number {
  const nums = d.match(/-?\d+(\.\d+)?/g)?.map(Number) ?? []
  let len = 0
  for (let i = 2; i + 1 < nums.length; i += 2) {
    len += Math.hypot(nums[i] - nums[i - 2], nums[i + 1] - nums[i - 1])
  }
  return len
}
```

Оценка по контрольным точкам завышает длину кривых Безье примерно на треть — это безопасно: пунктир длиннее пути гарантирует, что черта не начнётся с середины, а лишний запас не виден.

- [x] **Step 2: Проставить длины и задержки в разметке**

При обработке SVG заменить каждый `<path ... d="...">`, добавив атрибут `style` с вычисленными `--len` и `--delay`:

```tsx
let index = 0
const withLengths = svg.replace(/<path id="(kvg:[^"]+)" d="([^"]+)"/g, (match, id, d) => {
  const len = Math.ceil(approxLength(d)) + 20
  const delay = index * 0.4
  index++
  return `${match} style="--len:${len};--delay:${delay}s"`
})
```

Сохранить общее число черт, чтобы показать его в подписи.

- [x] **Step 3: Переписать CSS**

Заменить блок `.stroke-order` в `globals.css`:

```css
@media (prefers-reduced-motion: no-preference) {
  .stroke-order path {
    stroke-dasharray: var(--len);
    stroke-dashoffset: var(--len);
    animation: stroke-draw 0.45s linear forwards;
    animation-delay: var(--delay);
  }
}
```

Правила с `:nth-child` удаляются: задержка теперь приходит из переменной и работает для любого числа черт (сейчас их бывает до шести, правила были рассчитаны ровно на шесть).

- [x] **Step 4: Добавить повтор анимации**

Однократный показ при загрузке легко пропустить. Добавить кнопку «Ещё раз», которая перезапускает анимацию — например, сменой ключа React у контейнера.

Компонент станет клиентским; чтение файла остаётся серверным, поэтому разделить: серверная часть читает и передаёт готовую разметку, клиентская отвечает за перезапуск.

- [x] **Step 5: Проверить на длинных чертах**

Открыть карточки, где были самые длинные черты: の (`0306e`), ぬ (`0306c`), む (`0306d`), ふ (`03075`). Каждая черта должна проявляться от начала к концу.
