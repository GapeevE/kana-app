## Порядок выполнения

Задачи 1–6 не требуют базы данных и могут выполняться сразу.

Задача 7 заблокирована: нужны `DATABASE_URL` (проект в Neon, регион `eu-central-1`) и значение `INVITE_CODE` от владельца продукта. Все последующие задачи зависят от неё.

Внутри этапа задачи с непересекающимися зависимостями можно выполнять параллельно: 2 и 3 после 1; 11 после 8.

## После плана

Реализуется по мере необходимости, вне этих задач:

- Наполнение фактов в [`docs/content-facts.md`](../../../content-facts.md) и перенос в датасет
- Аудио произношения
- Восстановление доступа через сохраняемый код
- Сворачивание истории ответов старше года в агрегаты (спека, п. 12)
- Разделы «Кандзи» и «Грамматика»
