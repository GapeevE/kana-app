# Развёртывание

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Подключение к Neon через pooler — используется приложением |
| `DATABASE_URL_UNPOOLED` | Прямое подключение — используется миграциями |
| `AUTH_SECRET` | Подпись сессионных cookie |
| `INVITE_CODE` | Код приглашения для регистрации |

Генерация секрета:

    node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

`DATABASE_URL_UNPOOLED` обязателен: drizzle-kit не выполняет миграции через pgbouncer.

## Первое развёртывание

1. Создать проект в Neon.
2. Подключить репозиторий к Vercel.
3. Добавить интеграцию Neon в панели Vercel — `DATABASE_URL` и `DATABASE_URL_UNPOOLED` проставятся автоматически.
4. Добавить `AUTH_SECRET` и `INVITE_CODE` в переменные окружения Vercel.
5. Применить миграции с production-строкой подключения: `pnpm db:migrate`.
6. Запустить деплой.

## Локальная разработка

    pnpm install
    cp .env.example .env.local
    # заполнить значения
    pnpm db:migrate
    pnpm dev

## Миграции

    pnpm db:generate   # создать миграцию по изменениям схемы
    pnpm db:migrate    # применить
    pnpm db:studio     # просмотр данных

Миграции читают `.env.local`. Для production-базы подставить соответствующую строку подключения.

## Порядок черт

Файлы KanjiVG лежат в `public/kanjivg` и версионируются вместе с кодом — отдельного шага при развёртывании не требуется.

Повторная загрузка (например, после расширения датасета):

    node scripts/fetch-kanjivg.mjs

Скрипт пропускает уже загруженные файлы.

## Смена кода приглашения

Изменить `INVITE_CODE` в переменных окружения Vercel и передеплоить. Существующие аккаунты не затрагиваются.

## Эксплуатация

Бесплатный тир Neon засыпает через 5 минут простоя и просыпается самостоятельно при первом запросе — вмешательства не требуется.

Лимит хранилища — 0.5 ГБ. Таблица `answers` растёт неограниченно; при приближении к лимиту детальную историю старше года следует свернуть в агрегаты (спека, п. 12).
